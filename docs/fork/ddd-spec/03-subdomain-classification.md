# Subdomain Classification

| Loại | Subdomain | Lý do |
|---|---|---|
| Core | Domain Modeling | Mô hình hóa nghiệp vụ phức tạp |
| Core | Knowledge Management | Tri thức có nguồn và vòng đời |
| Core | Context Engineering | Chọn tri thức đúng cho từng nhiệm vụ |
| Core | Workflow | Điều phối quy trình có trạng thái |
| Core | Agent Orchestration | Điều phối thực thi và handoff |
| Supporting | Provider, Budget | Năng lực AI và kiểm soát chi phí |
| Supporting | Workspace, Skill, Quality, Artifact | Công cụ triển khai |
| Generic | Identity, Secrets, Audit, Notification | Hạ tầng dùng chung |

Phân loại sơ bộ, cần xác nhận qua Event Storming. Không đồng nhất subdomain với microservice.
