## 4. Kiểm tra phạm vi và phụ thuộc trước khi xóa

- `rg -n -i 'posthog|sentry|AO_TELEMETRY_|AO_SENTRY_DSN|AO_CLOUD_CONTROL_PLANE_URL|workos|authkit|cloud-client' backend frontend packages .github` để rà lại khi bắt đầu từng DV. Xem cả lockfiles, test và generated contract; bảng trên nhóm theo đường gửi, không liệt kê từng dòng test/locale.
- `rg -n 'https?://|fetch\(|http.NewRequest|httpsRequest|new WebSocket|sendBeacon|shell.openExternal' backend frontend packages .github` để phát hiện sender mới/URL gián tiếp. Phân loại loopback, GitHub/SCM user-selected, model provider, vendor AO trước khi sửa.
- DV-1 cần test phản chứng bằng transport/fetch/WebSocket fake ở daemon, Electron main/renderer và mobile. Test kiểm **0 request** tới PostHog, Sentry, `api.aoagents.dev`, upstream raw/release, kể cả override env, consent on, cached session và restart; đồng thời xác nhận local SQLite usage vẫn tăng.
