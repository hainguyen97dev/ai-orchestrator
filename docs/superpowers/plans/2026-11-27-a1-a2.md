# A1 Role + Skill có version, A2 Project Knowledge + snapshot — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Daemon lưu được `SkillDefinition` và `RoleProfile` toàn cục có version bất biến, `KnowledgePack` theo project từ file local, preview nguồn và tạo `KnowledgeSnapshot` ghim commit/hash/nội dung, có HTTP API. Chưa có UI và chưa gắn vào Flow (A3a).

**Architecture:** Theo pattern Cue/T1: `domain/` (kiểu + luật thuần) → `storage/sqlite` (migration, query, store) → `service/roleskill`, `service/knowledge` → `httpd/controllers` + `specgen` → wiring ở `daemon.go`/`api.go`. Version bất biến lưu ở bảng `*_versions(body_json)`, bảng `*_heads` giữ tên unique, `latest_version` và archive. Đọc file/git nằm trong adapter `adapters/knowledgesource`, service chỉ thấy interface `Source`.

**Tech Stack:** Go, SQLite + goose + sqlc, chi, code-first OpenAPI, `git` CLI qua `os/exec`.

**Spec:** [`docs/fork/specs/a1-a2-contract.md`](../../fork/specs/a1-a2-contract.md) (contract, nguồn chuẩn cho mọi tên/giá trị dưới đây). Bối cảnh: `docs/fork/specs/settings-role-skill-project-knowledge.md`, `role-skill-knowledge-model.md`, `project-knowledge-ddd-workflow.md`; roadmap §4–§6a.
