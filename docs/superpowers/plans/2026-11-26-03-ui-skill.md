# UI-S: skill UI thống nhất cho các màn mới — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:writing-skills (RED → GREEN → REFACTOR). Use superpowers:executing-plans for task order. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Có skill `ao-workflow-ui` để mọi agent (Claude, Codex) dựng các màn mới (Settings Roles/Skills/Knowledge/Tools, Flow Builder, Mission Control) cùng một kiểu, đúng `DESIGN.md`, không tự chế token hay component.

**Architecture:** Skill **không** chép lại `DESIGN.md`. Nó là công thức ráp màn mới từ primitive có sẵn: mỗi loại màn là một recipe (bố cục, component, trạng thái bắt buộc), kèm bảng ánh xạ trạng thái Flow → glyph/màu theo `DESIGN.md` §5, và checklist QA. File canonical đặt ở `.agents/skills/ao-workflow-ui/SKILL.md` (Codex và Claude cùng đọc được). `.claude/skills/ao-workflow-ui/SKILL.md` chỉ là con trỏ, giống `ao-desktop-dev`.

**Tech Stack:** Markdown skill; React + shadcn primitives `frontend/src/renderer/components/ui/*`; `packages/product-ui` cho view dùng chung với mobile.

**Spec:** `DESIGN.md` (§3 shell/route, §5 state/color, §6 tokens, §8 spacing, §9 components + "Settings language and agent-management rules", §12 resilience, §13 anti-patterns, §15 QA); wireframe ở `docs/fork/specs/workflow-blueprint.md` §3 và `settings-role-skill-project-knowledge.md` §2.

## Global Constraints

- Không thêm CSS token mới. Chỉ dùng token trong `frontend/src/styles/tokens.css` và semantic class trong `frontend/src/renderer/styles.css`.
- Component mới ưu tiên ráp từ `components/ui/*`. Cần primitive mới thì thêm vào `components/ui/` và có test, không viết inline trong màn.
- Mọi màn có đủ 4 trạng thái: loading (skeleton), empty, error (có hành động thử lại), stale/disconnected.
- View cần cho mobile về sau (Mission Control) đặt phần trình bày thuần trong `packages/product-ui/src/`, adapter dữ liệu ở renderer, theo mẫu `SessionsBoardView.tsx` + `SessionsBoardAdapters.tsx`.
- Frontend chỉ render read model và gửi action; không suy ra trạng thái run ở client.

## Review Focus

- Agent tạo badge màu riêng cho trạng thái Flow (ví dụ tím cho "waiting") thay vì dùng mapping §5 → kịch bản RED 2.
- Form version (Role/Skill/ToolProfile) ghi đè bản cũ mà không hiện version/conflict → kịch bản RED 1.
- Màn mới bỏ trạng thái empty/error, chỉ có happy path → kịch bản RED 3.
- Card bo góc + shadow riêng lẻ (đã bị `DESIGN.md` xếp vào nợ migration) bị chép sang màn mới → kiểm ở mọi kịch bản.
- Copy trong Settings dài dòng, thêm helper text thừa → kiểm theo "Settings language" §9.
