> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xoá app mobile, push điện thoại, remote host (LAN listener, tunnel, ghép cặp, `hostId`) và cloud (control plane Orchestrator.inc). Giữ Awake cho desktop.

**Architecture:** Ba đợt, mỗi đợt một nhánh và một lần merge:
- **A:** mobile và push. Phần này đứng riêng.
- **B:** remote host và `/mobile`, gồm phần còn lại của `mobilebridge` và `hostId`.
- **C:** cloud, cắt theo bề mặt.

Mỗi đợt cắt từ ngoài vào trong: frontend hoặc package JS trước, backend sau, doc cuối. Commit nào cũng phải build, typecheck và test xanh. Plan này chỉ ghi chi tiết đợt A. Đợt B và C sẽ được đo lại khi A merge xong, vì phạm vi của chúng phụ thuộc vào thứ A để lại.

**Tech Stack:** Go, TypeScript/React/Electron, Vitest, GitNexus CLI.

**Spec:** `docs/superpowers/specs/2026-11-27-ddd-platform-restructure-design.md` (§L1, K5); 17 §3 hàng F-13/F-14.

## Đợt B2: gỡ `hostId` còn sót ở frontend

**Số đo (`61271d8`):**
- 189 file không phải test, 3160 chỗ `hostId`; 76 file test.
- 4 shim do B1 tạo: `lib/local-daemon-client.ts` (119 importer), `hooks/useLocalHostConnection.ts` (15), `hooks/useNotificationHostCompatibility.ts` (1), `stores/session-pin-cache.ts` (2).

**Quy tắc:** sau B1, giá trị `hostId` luôn là `undefined` hoặc `LOCAL_HOST`. Mỗi chỗ gỡ phải giữ đúng hành vi local hiện tại:
- `hostId ? A : B` → `B`; `!hostId` → `true`; `hostId && X` → `false`; `hostId ?? LOCAL_HOST` → `LOCAL_HOST`.
- Bỏ prop, tham số và trường `hostId` / `host: HostId` khỏi component, hook, hàm và type nội bộ, rồi bỏ các nhánh chết đi kèm (kể cả nhánh `isRemote`).
- `clientForSessionHost(x)` → `apiClient`. Xoá cả 4 shim.
- `sessionUiKey(id, host)` → `sessionUiKey(id)`, vẫn trả về `id`, để không đổi key của state đã lưu. `LOCAL_HOST`, `refKey` và `Ref` chỉ giữ nếu còn chỗ dùng cho key local.
- Không đổi file sinh ra (`frontend/src/api/schema.ts`), không đụng backend. `ConversationFileReferenceRequest.hostId` (trường API) giữ nguyên; frontend chỉ thôi không gửi.
- Test: bỏ test chỉ kiểm hành vi remote. Test kiểm hành vi local thì giữ và gỡ `hostId` khỏi nó. **Không** xoá test của tính năng local.
- Cloud (`session.cloud`, `cloud-*`) giữ nguyên cho đợt C.
